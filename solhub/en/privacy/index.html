Privacy

Privacy

SolHub's principle: minimize data transfer. This page describes what we actually do — no invented promises.

Tool data: only in your browser

All online tools (JSON formatting, text counting, Base64, UUID, password generation, color conversion, image compression, QR codes, etc.) run locally in your browser. Your input is never sent to any server, and the page does not log input to the console.

  • Images you pick in the image compressor are <strong>not uploaded</strong> — processing happens entirely on-device.
  • The password generator uses the browser's native secure random API; generated passwords are never saved.
  • Tool pages include no ad SDKs, tracking SDKs or third-party analytics.

Community submissions & hosted tools

SolHub's community submission feature uses Tencent CloudBase (PostgreSQL) as its data backend:

  • <strong>Submitted content</strong> (name, description, links, developer info) is written to the CloudBase database on submit and <strong>auto-published</strong> to the community list — any visitor can see it.
  • <strong>Hosted tools</strong>: your uploaded self-contained HTML file is stored in CloudBase object storage (text/html only, ≤1MB) and runs in a <strong>sandboxed iframe</strong> here. The sandbox restricts scripts, so a hosted tool cannot read SolHub's main-site data or other submitters' content.
  • <strong>Fallback when no backend is configured</strong>: if CloudBase is unavailable, submissions are saved to this browser's <code>localStorage</code> (this browser only, never public).
  • The submit page never exposes database keys; the frontend only uses CloudBase's public anonymous identity (Publishable Key).

Local storage

  • When CloudBase is unavailable or submission fails, the form saves a draft to this browser's <code>localStorage</code>. It <strong>exists only in this browser</strong> and is never shown to other visitors.
  • If local bookmarks are added later, they will likewise stay in this browser only.

Capabilities that need network requests

The following cases trigger network requests; purpose and destination are explicit:

  • Community submission writes & reads: requests go to CloudBase (Tencent Cloud, ap-shanghai environment), transmitting only what you entered in the form plus public list data.
  • Hosted tool loading: clicking “Open tool” requests a temporary URL for that tool's HTML from CloudBase object storage; <strong>the URL expires within 1 hour</strong>.
  • Product website links are opened by visitors themselves; SolHub never crawls or collects their content automatically.

Static hosting

SolHub is a static site deployed on static hosting such as GitHub Pages. Hosting platforms may record standard access logs (IP, browser type, request time) for infrastructure purposes — this is common hosting behavior; SolHub itself runs no analytics scripts.

Changes

This page will be updated as the site evolves. If analytics, login or other data processing is introduced later, we will update this page before shipping the feature.
