Privacy

隐私说明

SolHub 的原则是：尽量减少数据传输。本页描述我们实际做了什么，不虚构安全承诺。

工具数据：只在你的浏览器里

所有在线工具（JSON 格式化、文本统计、Base64、UUID、密码生成、颜色转换、图片压缩、二维码等） 都在浏览器本地运行。你的输入内容不会发送到任何服务器，页面也不通过控制台记录输入。

  • 图片压缩工具中你选择的图片不会上传，处理全部在本地完成。
  • 密码生成器使用浏览器原生安全随机数，生成的密码不会保存。
  • 工具页面不加入广告 SDK、跟踪 SDK 或第三方分析服务。

本地存储

  • 提交表单在未配置远程接口时，会把草稿保存到当前浏览器的 localStorage。它只存在于当前浏览器，不会公开给其他访问者，也不会同步到任何服务器。
  • 未来若加入本地收藏功能，同样只保存在当前浏览器。

需要网络请求的能力

以下情况会发起网络请求，目的与目标均已明确：

  • 如果你配置了远程提交接口（PUBLIC_SOLHUB_SUBMIT_ENDPOINT），提交内容会发送到该接口；未配置则不会。
  • 如果你配置了 GitHub 投稿仓库（PUBLIC_SOLHUB_ISSUE_REPO），系统会生成预填 Issue 链接，由你自己点击在 GitHub 上提交。
  • 产品官网链接由访问者自行点击打开，SolHub 不会自动抓取或收集其内容。

页面静态托管

SolHub 是静态网站，部署于 GitHub Pages 等静态托管平台。托管平台可能出于基础设施目的记录标准访问日志 （IP、浏览器类型、请求时间等），这是托管服务的通用行为，SolHub 本身不部署任何统计脚本。

变更

本说明会随网站功能变化更新。如果未来引入分析、登录或其他数据处理能力，我们会先更新此页面， 再上线对应功能。
