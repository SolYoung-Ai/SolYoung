Privacy

隐私说明

SolHub 的原则是：尽量减少数据传输。本页描述我们实际做了什么，不虚构安全承诺。

工具数据：只在你的浏览器里

所有在线工具（JSON 格式化、文本统计、Base64、UUID、密码生成、颜色转换、图片压缩、二维码等）都在浏览器本地运行。你的输入内容不会发送到任何服务器，页面也不通过控制台记录输入。

  • 图片压缩工具中你选择的图片<strong>不会上传</strong>，处理全部在本地完成。
  • 密码生成器使用浏览器原生安全随机数，生成的密码不会保存。
  • 工具页面不加入广告 SDK、跟踪 SDK 或第三方分析服务。

社区提交与托管工具

SolHub 的社区提交功能使用腾讯云 CloudBase（PostgreSQL）作为数据后端：

  • <strong>提交内容</strong>（名称、介绍、链接、开发者信息）在提交时写入 CloudBase 数据库，并<strong>自动公开</strong>到社区列表，任何访问者都能看到。
  • <strong>托管工具</strong>：你上传的自包含 HTML 文件会存入 CloudBase 对象存储（仅限 text/html、≤1MB），并在本站的<strong>沙箱 iframe</strong> 中运行。沙箱限制脚本能力，托管工具无法读取 SolHub 主站数据或其他提交者的内容。
  • <strong>未配置后端时的回退</strong>：如果 CloudBase 不可用，提交内容会保存到当前浏览器的 <code>localStorage</code>（仅存在于当前浏览器，不会公开）。
  • 提交页不会暴露任何数据库密钥；前端仅使用 CloudBase 的公开匿名身份（Publishable Key）。

本地存储

  • 提交表单在 CloudBase 不可用或提交失败时，会把草稿保存到当前浏览器的 <code>localStorage</code>。它<strong>只存在于当前浏览器</strong>，不会公开给其他访问者。
  • 未来若加入本地收藏功能，同样只保存在当前浏览器。

需要网络请求的能力

以下情况会发起网络请求，目的与目标均已明确：

  • 社区提交写入与读取：请求发送到 CloudBase（腾讯云，ap-shanghai 环境），仅传输你在表单中填写的内容与公开列表数据。
  • 托管工具加载：点击「打开工具」时，向 CloudBase 对象存储请求该工具 HTML 的临时访问地址，<strong>该地址 1 小时内有效</strong>。
  • 产品官网链接由访问者自行点击打开，SolHub 不会自动抓取或收集其内容。

页面静态托管

SolHub 是静态网站，部署于 GitHub Pages 等静态托管平台。托管平台可能出于基础设施目的记录标准访问日志（IP、浏览器类型、请求时间等），这是托管服务的通用行为，SolHub 本身不部署任何统计脚本。

变更

本说明会随网站功能变化更新。如果未来引入分析、登录或其他数据处理能力，我们会先更新此页面，再上线对应功能。
